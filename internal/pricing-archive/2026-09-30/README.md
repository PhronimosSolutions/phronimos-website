# Public pricing archive — 2026-09-30

This folder preserves the public pricing removed from phronimos.io on
2026-09-30. Nothing under `internal/` is part of the Astro build.

## Archived offer ladder

- Agent Reliability Review: **$999 flat**
- Agent Implementation Sprint: **from $3,500**
- Fractional AI Officer: **$5,000 per month**
- First-year example formerly used in FAQ copy: **from $63,500**

The former public policy credited the Review fee in full toward an Agent
Implementation Sprint or the first month of a Fractional AI Officer retainer.
Sprint scope changes were re-priced in writing before work continued. The
Fractional AI Officer was described as a flat, month-to-month retainer with
30 days' notice.
